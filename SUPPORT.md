# Getting help

Meta G Link Direct is a personal open-source project with best-effort support: there is no guaranteed response time.

1. Read the [README](README.md), especially [Troubleshooting](README.md#troubleshooting) and [Known limits](README.md#known-limits).
2. Search the [existing issues](https://github.com/RandyNorthrup/meta-g-link-direct/issues?q=is%3Aissue).
3. If nothing matches, [open a bug report](https://github.com/RandyNorthrup/meta-g-link-direct/issues/new/choose).

A useful report includes:

- the plugin version, the OBS version and whether OBS is portable, Steam or installed;
- the Windows version, and the Bluetooth and Wi-Fi adapter models;
- what you did, what you expected and what happened;
- the `[meta-g-link-direct]` lines from the OBS log (*Help → Log Files*); they contain status only.

Never paste Bluetooth or network addresses, Wi-Fi names or passwords, Meta login addresses or codes, tokens, or anything from `%LOCALAPPDATA%\MetaGLinkDirect`.

Security problems go through [SECURITY.md](SECURITY.md), not public issues.

If the project helps you, you can [sponsor it on GitHub](https://github.com/sponsors/RandyNorthrup) or [donate through PayPal](https://www.paypal.com/donate/?hosted_button_id=Q9VC7B42R7K82).
